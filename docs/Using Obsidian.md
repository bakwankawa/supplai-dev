## Buka vault yang berisi dokumentasi

`/Users/robertusrotama/Documents/Code/supplai-dev/docs`

Buka [[Home]] sebagai halaman awal.

Jika seluruh folder `supplai-dev` sudah dibuka sebagai vault, catatan yang sama tersedia di `docs/Home.md`. Tidak perlu membuat ulang catatan atau menggambar hubungan satu per satu.

## Garis graph muncul otomatis

Graph view menampilkan note sebagai titik dan internal link sebagai garis. Menulis `[[Frontend Map]]` di sebuah note akan menghubungkannya ke note tersebut. Tidak perlu menggambar garis secara manual.

Pilih **Open graph view** di sidebar untuk melihat seluruh hubungan. Local graph hanya menampilkan hubungan note yang sedang dibuka. Canvas adalah papan susun visual yang berbeda dari Graph view.

Contoh hubungan yang sudah tersedia: [[Home]] → [[Frontend Map]] → [[Data Flow]] → [[Frontend Performance Audit]].

Panduan resmi: https://help.obsidian.md/plugins/graph dan https://help.obsidian.md/manage-vaults.
