# Population-Based Volume Sizing — Implementation Plan (1 of 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the hardcoded 1,000-ton stabilisation stock in `supplai/match.py` with volumes derived from each province's measured consumption, bounded so a shipment cannot depress local prices, and report whether real intervention is large enough to matter.

**Architecture:** A new `supplai/kebutuhan.py` turns four committed reference tables (population, per-capita consumption, own-price elasticity, national balance sheets) into per-province monthly market size and intervention volume under three risk postures read off the existing calibrated p10/p50/p90 forecast band. `match.py` consumes it instead of its own heuristics. A new `rebuild_plan.py` regenerates `flows.parquet` from existing forecast artifacts in seconds, so nothing here requires a 15-minute retrain.

**Tech Stack:** Python 3.11.15 at `/opt/conda/envs/dicoding/bin/python` (pandas 2.2.2, numpy 1.26.4, scipy 1.13.1, pytest 9.0.3, openpyxl 3.1.5). No new dependencies.

**Spec:** `supplai-dev/docs/superpowers/specs/2026-09-06-population-sizing-and-ai-narration-design.md`

**Scope note:** This is plan 1 of 2. Plan 2 (LLM narration layer + front-end surfaces) is written after this one lands, so its fact blocks reference the final column names produced here.

- **Interpreter:** always `/opt/conda/envs/dicoding/bin/python`. The default `python3` (3.10.19, base) lacks lightgbm/tensorflow/prophet. Nothing in this plan needs them, but use the same interpreter throughout so results match the pipeline.
- **Working directory:** `/home/jupyter/kawa-temp/hackathon_phase2`. All paths below are relative to it unless prefixed `supplai-dev/`.

- **Language:** code and docstrings in English (matching `supplai/*.py`); user-facing strings and CSV comments in Indonesian (matching the dashboard).
- **Volume is reported with a 95% CI** derived from the published elasticity standard error. Never a bare point estimate.

Create `ingest_neraca.py`:

```python
"""Parse the Bapanas balance-sheet spreadsheets into one tidy CSV.

The six files share a shape but not a layout: header rows differ, the year
column is unlabelled, and the two Bawang Merah files are byte-identical
duplicates. Rather than guess, each file declares where its columns are.

Run:  /opt/conda/envs/dicoding/bin/python ingest_neraca.py
"""

from __future__ import annotations

import datetime
from pathlib import Path

import pandas as pd

SRC = Path("additional data")
OUT = Path("data/neraca_nasional.csv")

# file -> (SupplAi name, header row index, column indices for
#          total_ketersediaan / total_kebutuhan / neraca)
BERKAS = {
    "Neraca Ketersediaan dan Kebutuhan Beras.xlsx": ("Beras Medium", 3, 6, 9, 10),
    "Neraca Ketresediaan dan Kebutuhan Bawang Merah.xlsx": ("Bawang Merah", 2, 7, 12, 13),
    "Neraca Ketersediaan dan Kebutuhan Gula.xlsx": ("Gula Pasir", 2, 4, 8, 9),
    "Neraca Ketersediaan dan Kebutuhan Cabai Besar.xlsx": ("Cabai Besar", 1, 4, 8, 9),
    "Neraca Ketersediaan dan Kebutuhan Cabai Rawit.xlsx": ("Cabai Rawit", 1, 4, 8, 9),
    "Neraca Ketersediaan dan Kebutuhan Bulanan Daging Sapi .xlsx": ("Daging Sapi", 4, 9, 12, 13),
}


def baca(path: Path, kom: str, hdr: int, c_ada: int, c_butuh: int, c_neraca: int):
    raw = pd.read_excel(path, sheet_name=0, header=None)
    rows = []
    for _, r in raw.iloc[hdr + 1 :].iterrows():
        tahun = pd.to_numeric(r.iloc[0], errors="coerce")
        if pd.isna(tahun) or not (2020 <= tahun <= 2030):
            continue
        rows.append({
            "komoditas": kom,
            "tahun": int(tahun),
            "total_ketersediaan_ton": pd.to_numeric(r.iloc[c_ada], errors="coerce"),
            "total_kebutuhan_ton": pd.to_numeric(r.iloc[c_butuh], errors="coerce"),
            "neraca_ton": pd.to_numeric(r.iloc[c_neraca], errors="coerce"),
        })
    return rows


def main() -> None:
    rows = []
    for nama, (kom, hdr, a, b, c) in BERKAS.items():
        rows += baca(SRC / nama, kom, hdr, a, b, c)
    df = pd.DataFrame(rows).dropna(subset=["neraca_ton"])
    df = df.drop_duplicates(subset=["komoditas", "tahun"]).sort_values(["komoditas", "tahun"])
    for c in ("total_ketersediaan_ton", "total_kebutuhan_ton", "neraca_ton"):
        df[c] = df[c].round().astype("Int64")
    with open(OUT, "w", encoding="utf-8") as f:
        f.write("# Neraca ketersediaan dan kebutuhan pangan nasional (ton/tahun)\n")
        f.write("# Sumber: Badan Pangan Nasional / BPS, berkas dari staf ahli Komisi IV DPR RI\n")
        f.write("# Berkas asal: 'additional data/Neraca *.xlsx' (satu duplikat Bawang Merah dibuang)\n")
        f.write(f"# Diurai: {datetime.date.today()} oleh ingest_neraca.py\n")
        f.write("# CATATAN: Bawang Putih tidak punya neraca (sekitar 95% impor).\n")
        df.to_csv(f, index=False)
    print(f"{OUT}: {len(df)} baris, {df['komoditas'].nunique()} komoditas")


if __name__ == "__main__":
    main()
```

```python
Four of the six forecast commodities appear in the regional file and get a real
per-province figure. Bawang Merah and Bawang Putih collapse into a "Sayur"

Run:  /opt/conda/envs/dicoding/bin/python ingest_konsumsi.py

from __future__ import annotations

import datetime
from pathlib import Path

import pandas as pd

SRC = Path("additional data/konsumsi_pangan_kabkota_2021_2025.xlsx")
OUT = Path("data/konsumsi_per_kapita.csv")
TAHUN = 2025

# SupplAi name -> (label in the source file, national anchor in kg/capita/year).
#
# The regional file and Susenas measure slightly different things: its "Beras"
# runs about 12% above the Susenas "Beras" line item, the same definitional gap
# the spec records (79.08 line item / 88.76 this file / 91.58 all rice-bearing
# foods). Taken raw, this table puts national rice consumption 10.85% above the
# Bapanas balance sheet. So we use it for what it is good at — the *shape* of
# regional variation — and anchor the *level* to the Susenas figure, which
# reconciles with the balance sheet to 0.31%. Rescaling is a single factor per
# commodity, so every province keeps its relative position exactly.
REGIONAL = {
    "Beras Medium": (["beras"], 79.077),
    "Daging Ayam": (["daging unggas"], 8.028),
    "Telur Ayam": (["telur"], 6.969),
    "Minyak Goreng": (["minyak sawit"], 11.911),
}
# Statistik Konsumsi Pangan 2024 (Kementan Pusdatin, dari Susenas Maret BPS),
# Tabel 4.1a dan 4.2a — kg/kapita/tahun.
NASIONAL = {"Bawang Merah": 2.861, "Bawang Putih": 1.928}

# The source uses the post-2022 38-province split; the model uses 34.
GABUNG = {
    "Papua Selatan": "Papua", "Papua Tengah": "Papua", "Papua Pegunungan": "Papua",
    "Papua Barat Daya": "Papua Barat",
}


def main() -> None:
    prov34 = sorted(pd.read_parquet("artifacts/centroids.parquet")["provinsi"])
    raw = pd.read_excel(SRC, sheet_name=0, header=0)
    raw.columns = [str(c).strip() for c in raw.columns]
    raw["kom"] = raw["Komoditas"].astype(str).str.strip().str.lower()
    raw["val"] = pd.to_numeric(raw["Konsumsi_Pangan"], errors="coerce")
    raw["prov"] = raw["Provinsi"].astype(str).str.strip().replace(GABUNG)
    year = raw[(raw["Tahun"] == TAHUN)].dropna(subset=["val"])

    pop = (pd.read_csv("data/populasi_provinsi_2025.csv", comment="#")
           .set_index("provinsi")["populasi_2025"].reindex(prov34))

    rows = []
    for kom, (labels, anchor) in REGIONAL.items():

            })

              f"(rata tertimbang {rata_tertimbang:.2f} -> {anchor})")
    for kom, val in NASIONAL.items():
        for p in prov34:
            rows.append({"komoditas": kom, "provinsi": p,
                         "kg_per_kapita_tahun": val, "resolusi": "nasional"})

    df = pd.DataFrame(rows).sort_values(["komoditas", "provinsi"])
    with open(OUT, "w", encoding="utf-8") as f:
        f.write("# Konsumsi per kapita per provinsi (kg/kapita/tahun)\n")
        f.write(f"# Regional ({TAHUN}): berkas kab/kota dari staf ahli Komisi IV DPR RI,\n")
        f.write("#   'konsumsi_pangan_kabkota_2021_2025.xlsx', dirata-ratakan ke provinsi.\n")
        f.write("# Nasional: Statistik Konsumsi Pangan 2024 (Kementan Pusdatin, dari Susenas\n")
        f.write("#   Maret BPS), Tabel 4.1a Bawang Merah dan 4.2a Bawang Putih.\n")
        f.write("# KALIBRASI: angka regional memakai definisi 'Beras' yang lebih luas dari pos\n")
        f.write("#   Susenas, sehingga apa adanya ia 10,85% di atas neraca Bapanas. Bentuk\n")
        f.write("#   ragam antar-provinsi dipertahankan, levelnya diskalakan satu faktor per\n")
        f.write("#   komoditas ke angka Susenas nasional; hasilnya 0,31% dari neraca.\n")
        f.write("# Minyak Goreng bersatuan liter pada sumbernya; lihat catatan di spec.\n")
```

```python
"""Turn population and consumption into how many tonnes an intervention needs.

`match.py` used to distribute an assumed 1,000-tonne stock in proportion to the
size of a predicted price spike. That number was not measured, and the result
was a plan shipping 800 t of rice into a province whose entire monthly market is
under 5,000 t — 16% of the market, to counter a 2% price rise.

This module replaces the assumption. Market size comes from measured per-capita
consumption times BPS population. Intervention volume comes from the own-price
elasticity of demand: countering an X% rise needs eps*X% of monthly consumption,
which is a small number because that is all that is required — not because a cap
was imposed afterwards.

Every input is a committed CSV carrying its own provenance. `cakupan()` reports
the resolution of each input per commodity so no caller has to assume.
"""

from __future__ import annotations

from pathlib import Path

import pandas as pd

from .wilayah import region_of


class Kebutuhan:
    def __init__(self, data_dir: str | Path = "data") -> None:
        d = Path(data_dir)
        self.populasi = (
            pd.read_csv(d / "populasi_provinsi_2025.csv", comment="#")
            .set_index("provinsi")["populasi_2025"]
        )
        self.konsumsi = pd.read_csv(d / "konsumsi_per_kapita.csv", comment="#")
        self.elastisitas = pd.read_csv(d / "elastisitas.csv", comment="#")
        self.neraca = pd.read_csv(d / "neraca_nasional.csv", comment="#")
        self._komoditas = set(self.konsumsi["komoditas"])

    # -- market size ------------------------------------------------------
    def konsumsi_bulanan(self, komoditas: str) -> pd.Series:
        """Monthly consumption in tonnes, per province."""
        if komoditas not in self._komoditas:
            raise KeyError(
                f"{komoditas!r} has no consumption coefficient; "
                f"known: {sorted(self._komoditas)}"
            )
        k = self.konsumsi[self.konsumsi["komoditas"] == komoditas]
        per_kapita = k.set_index("provinsi")["kg_per_kapita_tahun"]
        # kg/capita/year * people / 1000 -> tonnes/year; / 12 -> tonnes/month
        return (per_kapita * self.populasi / 1000 / 12).dropna().sort_index()

    # -- coverage ---------------------------------------------------------
    def cakupan(self) -> pd.DataFrame:
        punya_neraca = set(self.neraca["komoditas"])
        rows = []
        for kom in sorted(self._komoditas):
            k = self.konsumsi[self.konsumsi["komoditas"] == kom]
            e = self.elastisitas[
                (self.elastisitas["komoditas"] == kom)
                & (self.elastisitas["wilayah"] != "Indonesia")
            ]
            rows.append({
                "komoditas": kom,
                "resolusi_konsumsi": "regional" if (k["resolusi"] == "regional").any() else "nasional",
                "resolusi_elastisitas": "regional" if bool(e["signifikan"].all()) else "campuran",
                "punya_neraca": kom in punya_neraca,
            })
        return pd.DataFrame(rows)
```

```python
    # -- elasticity -------------------------------------------------------
    def epsilon_untuk(self, komoditas: str, provinsi: str) -> tuple[float, float, str]:
        """Absolute own-price elasticity, its standard error, and where it came
        from. A regional estimate whose 95% CI crosses zero is not usable — the
        source itself calls it uncertain — so those fall back to national."""
        e = self.elastisitas[self.elastisitas["komoditas"] == komoditas]
        if e.empty:
            raise KeyError(f"{komoditas!r} has no elasticity")
        reg = e[e["wilayah"] == region_of(provinsi)]
        if not reg.empty and bool(reg.iloc[0]["signifikan"]):
            r = reg.iloc[0]
            return abs(float(r["epsilon"])), float(r["se"]), "regional"
        nat = e[e["wilayah"] == "Indonesia"].iloc[0]
        return abs(float(nat["epsilon"])), float(nat["se"]), "nasional"

    # -- intervention volume ----------------------------------------------
    def volume_intervensi(
        self, komoditas: str, kenaikan_persen: pd.Series
    ) -> pd.DataFrame:
        """Tonnes needed to offset the given predicted rise, per province.

        volume = eps * kenaikan% * konsumsi_bulanan

        The 95% interval comes from the published standard error, so the output
        carries the source's own uncertainty rather than a made-up range. The
        volume is clipped at the size of the local market: beyond that the model
        is extrapolating past anything the elasticity was estimated on.
        """
        q = self.konsumsi_bulanan(komoditas)
        rows = {}
        for prov, naik in kenaikan_persen.items():
            if prov not in q.index:
                continue
            eps, se, src = self.epsilon_untuk(komoditas, prov)
            naik = max(float(naik), 0.0)
            scale = naik / 100.0 * float(q[prov])
            lo_eps = max(eps - 1.96 * se, 0.0)
            rows[prov] = {
                "volume_ton": min(eps * scale, float(q[prov])),
                "ci_bawah": min(lo_eps * scale, float(q[prov])),
                "ci_atas": min((eps + 1.96 * se) * scale, float(q[prov])),
                "epsilon": eps,
                "epsilon_sumber": src,
            }
        return pd.DataFrame.from_dict(rows, orient="index")
```

```python
        Compares the computed requirement against what Gerakan Pangan Murah
        actually delivered, converting its per-event budget to tonnes at the
        local price.

        THREE CAVEATS travel with this number and must be rendered beside it:

        (2) the per-event budget is a 2027 plan applied to 2026 realisations;
```

```python
def build_plan(
    forecast: pd.DataFrame,
    dist: pd.DataFrame,
    komoditas: str,
    kebutuhan,
    postur: str = "seimbang",
    forecast_path: pd.DataFrame | None = None,
    spike_threshold: float = 2.0,
    thresholds: dict | None = None,
    kapasitas_share: float = 0.10,
) -> dict:
    """Solve the redistribution LP for one commodity under one risk posture.

    Volumes on the destination side are measured, not assumed: they come from
    `kebutuhan.volume_intervensi`, which is elasticity times the predicted rise
    times that province's own monthly consumption. The source side is still a
    heuristic — per-province production is not published — but it is now bounded
    so a source cannot ship itself into deficit. Each row says which it is in
    `dasar_takaran`.
    """
    f = forecast[forecast["komoditas"] == komoditas].set_index("provinsi").copy()
    f = f.dropna(subset=["perubahan_persen"])
    if f.empty:
        return {"status": "kosong", "flows": pd.DataFrame(), "summary": {}}

    konsumsi = kebutuhan.konsumsi_bulanan(komoditas)
    anggaran = kebutuhan.anggaran_nasional(komoditas)
    median_price = f["harga_kini"].median()

    # Classification uses the POINT forecast under every posture, so the route
    # map stays the same and the posture switch moves volumes rather than
    # reshuffling the map. Classifying on `hi` emptied the surplus set entirely
    # — under the p90 path almost every province is rising, so nobody qualifies
    # as a spare source.
    deficit = f[(f["perubahan_persen"] >= spike_threshold)
                & (f["harga_kini"] >= median_price)].copy()
    surplus = f[(f["harga_kini"] < median_price)
                & (f["perubahan_persen"] < spike_threshold)].copy()
    if deficit.empty or surplus.empty:
        return {"status": "tidak ada pasangan surplus-defisit",
                "flows": pd.DataFrame(), "summary": {},
                "anggaran_nasional": anggaran}

    # --- destination: measured need under this posture, then the cap --------
    naik, _harga = _kenaikan(forecast, forecast_path, komoditas, postur)
    deficit["perubahan_persen"] = (
        naik.reindex(deficit.index).clip(lower=0).fillna(0.0)
    )
    vol = kebutuhan.volume_intervensi(komoditas, deficit["perubahan_persen"])
    deficit = deficit.join(vol, how="inner")
    if deficit.empty:
        return {"status": "tidak ada kebutuhan terukur", "flows": pd.DataFrame(),
                "summary": {}, "anggaran_nasional": anggaran}

    # Bapanas treats a price fall as seriously as a rise, so the same
    # per-commodity band that makes a rise "Info" bounds how far we may push
    # price down. p70 of that commodity's own history, applied downward.
    # No silent default for a SAFETY limit. p70 is what bounds how far a
    # shipment may push the destination price down; guessing it at 5.0 made the
    # cap 2.3x looser than rice's real 2.14 and let the aggressive posture ship
    # 138 t where the calibrated cap allows 59 t. A cap we invented is not a cap.
    if not thresholds or komoditas not in thresholds:
        raise ValueError(
            f"{komoditas!r}: no percentile thresholds supplied, so the low-price "
            f"cap cannot be computed. Pass the thresholds table from "
            f"artifacts/thresholds.parquet — do not let this default."
        )
    p70 = float(thresholds[komoditas]["p70"])
    q_tujuan = konsumsi.reindex(deficit.index)
    pagu_pasar = deficit["epsilon"] * (p70 / 100.0) * q_tujuan
    deficit["kebutuhan_ton"] = deficit["volume_ton"].clip(upper=pagu_pasar)

    if deficit["kebutuhan_ton"].sum() <= 0:
        # The conservative posture reaches here legitimately: at p10 no province
        # is predicted to rise, so the honest answer is to ship nothing.
        return {"status": "tidak perlu intervensi", "flows": pd.DataFrame(),
                "summary": {}, "anggaran_nasional": anggaran}

    # --- source: declared heuristic, bounded so it creates no new deficit ---
    surplus["keunggulan"] = (median_price - surplus["harga_kini"]) / median_price
    q_asal = konsumsi.reindex(surplus.index).fillna(0.0)
    total_pool = anggaran if anggaran is not None else float(deficit["kebutuhan_ton"].sum())
    surplus["kapasitas_ton"] = (
        total_pool * surplus["keunggulan"] / surplus["keunggulan"].sum()
    ).clip(upper=q_asal * kapasitas_share)

    # Demand is now MEASURED, so it belongs on the constraint side as a floor:
    # the LP's job is to source a known requirement at least cost. Making it a
    # ceiling instead — with every freight cost positive and nothing pulling
    # volume in — makes shipping nothing the optimal answer, and the solver
    # dutifully returns an empty plan. If sources cannot cover the requirement,
    # scale every destination down proportionally rather than return infeasible.
    # Keep the measured requirement before any capacity-driven shrinking, so
    # `dasar_takaran` below can tell whether a route's number was set by
    # measurement or by the source-side heuristic. Comparing against the scaled
    # value would always agree with itself and the label would never flip.
    deficit["kebutuhan_terukur_ton"] = deficit["kebutuhan_ton"]
    if deficit["kebutuhan_ton"].sum() > surplus["kapasitas_ton"].sum():
        deficit["kebutuhan_ton"] *= (
            surplus["kapasitas_ton"].sum() / deficit["kebutuhan_ton"].sum()
        )

    S, D = list(surplus.index), list(deficit.index)
    ns, nd = len(S), len(D)
    km = dist.loc[S, D].to_numpy()
    c = (km * COST_PER_TON_KM).flatten()

    A_ub, b_ub = [], []
    for i in range(ns):  # a source ships at most its capacity
        row = np.zeros(ns * nd); row[i * nd : (i + 1) * nd] = 1
        A_ub.append(row); b_ub.append(surplus["kapasitas_ton"].iloc[i])
    for j in range(nd):  # a destination receives at least its requirement
        row = np.zeros(ns * nd); row[j::nd] = -1
        A_ub.append(row); b_ub.append(-deficit["kebutuhan_ton"].iloc[j])
    if anggaran is not None:
        A_ub.append(np.ones(ns * nd)); b_ub.append(float(anggaran))

    res = linprog(c, A_ub=np.array(A_ub), b_ub=np.array(b_ub),
                  bounds=(0, None), method="highs")
    if not res.success:
        return {"status": f"solver gagal: {res.message}", "flows": pd.DataFrame(),
                "summary": {}, "anggaran_nasional": anggaran}

    x = res.x.reshape(ns, nd)
    rows = []
    for i in range(ns):
        for j in range(nd):
            if x[i, j] < 0.01:  # ignore dust; volumes are far smaller now
                continue
            rows.append({
                "komoditas": komoditas, "dari": S[i], "ke": D[j],
                "volume_ton": x[i, j], "jarak_km": km[i, j],
                "biaya_rp": x[i, j] * km[i, j] * COST_PER_TON_KM,
                "harga_asal": surplus["harga_kini"].iloc[i],
                "harga_tujuan": deficit["harga_kini"].iloc[j],
                "prediksi_kenaikan": deficit["perubahan_persen"].iloc[j],
                "konsumsi_tujuan_ton_bulan": float(q_tujuan.iloc[j]),
                "epsilon": float(deficit["epsilon"].iloc[j]),
                "epsilon_sumber": deficit["epsilon_sumber"].iloc[j],
                "postur": postur,
            })
    flows = pd.DataFrame(rows)
    if flows.empty:
        return {"status": "tidak ada rute ekonomis", "flows": flows,
                "summary": {}, "anggaran_nasional": anggaran}
    flows = flows.sort_values("prediksi_kenaikan", ascending=False)

    flows["persen_pasar"] = (
        flows["volume_ton"] / flows["konsumsi_tujuan_ton_bulan"] * 100
    )

    # --- carry the confidence interval into the shipped numbers -------------
    # The CI belongs to the requirement, so scale it by whatever the low-price
    # cap and the capacity scale-down did to the point estimate, then split it
    # across the routes serving a destination in proportion to what each
    # delivers. Dropping it here would leave the output table stating a volume
    # with no uncertainty attached, which the whole design exists to avoid.
    rasio = (deficit["kebutuhan_ton"]
             / deficit["volume_ton"].replace(0, np.nan)).fillna(0.0)
    diterima = flows.groupby("ke")["volume_ton"].transform("sum")
    bagian = flows["volume_ton"] / diterima.replace(0, np.nan)
    flows["volume_ci_bawah"] = bagian * flows["ke"].map(deficit["ci_bawah"] * rasio)
    flows["volume_ci_atas"] = bagian * flows["ke"].map(deficit["ci_atas"] * rasio)

    # --- say which basis actually set each number ---------------------------
    # A destination that received less than its requirement had its volume
    # decided by the source-side heuristic (capacity, or the proportional
    # scale-down), not by measurement. Stamping every route "terukur" asserted a
    # distinction the code never computed.
    butuh = flows["ke"].map(deficit["kebutuhan_terukur_ton"])
    flows["dasar_takaran"] = np.where(
        diterima >= butuh - 1e-6, "terukur", "diasumsikan"
    )
    # thresholds is guaranteed present by the guard above, so there is no
    # fixed-cut fallback here any more — it would have been a second invented
    # scale sitting beside the calibrated one.
    t = thresholds[komoditas]
    flows["urgensi"] = pd.cut(
        flows["prediksi_kenaikan"],
        bins=[-np.inf, t["p70"], t["p85"], t["p95"], np.inf],
        labels=["Normal", "Info", "Warning", "Kritis"],
    )
    flows["hemat_rp"] = (
        (flows["harga_tujuan"] * (1 + flows["prediksi_kenaikan"] / 100)
         - flows["harga_asal"]) * flows["volume_ton"] * 1_000
    ) - flows["biaya_rp"]

    butuh = flows.groupby("ke")["volume_ton"].sum()
    harga_tujuan = flows.groupby("ke")["harga_tujuan"].first()
    kec = kebutuhan.kecukupan(komoditas, butuh, harga_tujuan)
    flows["kecukupan_persen"] = flows["ke"].map(kec["kecukupan_persen"])

    return {
        "status": "ok", "flows": flows, "surplus": surplus, "deficit": deficit,
        "anggaran_nasional": anggaran,
        "summary": {
            "total_ton": float(flows["volume_ton"].sum()),
            "total_biaya": float(flows["biaya_rp"].sum()),
            "total_hemat": float(flows["hemat_rp"].sum()),
            "n_rute": int(len(flows)),
            "n_sumber": int(flows["dari"].nunique()),
            "n_tujuan": int(flows["ke"].nunique()),
            "jarak_rata": float(flows["jarak_km"].mean()),
            "persen_pasar_maks": float(flows["persen_pasar"].max()),
            "postur": postur,
        },
    }
```
