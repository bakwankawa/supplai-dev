# SupplAI Knowledge Base

Pusat dokumentasi project SupplAI. Folder `docs` ini dapat dibuka sebagai vault di Obsidian.

## Mulai di sini

- [[Project Overview]] — teknologi, perintah kerja, dan alur data.
- [[Decisions]] — catat keputusan teknis beserta alasannya.
- [[Research]] — kumpulkan pertanyaan riset dan sumbernya.
- [[Frontend Map]] — halaman, komponen, dan tanggung jawabnya.
- [[Data Flow]] — jalur data dari artifacts sampai tampilan.
- [[Prediction Reports]] — narasi hasil ML dan laporan PDF untuk telaah keputusan.
- [[Frontend Performance Audit]] — hasil pengukuran dan optimasi frontend.
- [[Using Obsidian]] — membuka vault dan melihat hubungan catatan.
